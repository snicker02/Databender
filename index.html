Workflow: load → stack effects or hand-edit bytes → Save .bmp to keep the real corrupted file, then Load that .bmp back in to keep bending it (PNG export re-encodes clean). Header is protected by default so the file always decodes; the decoder is custom and tolerant, so broken byte streams shear instead of failing.
